# CodePair

Сайт: **https://codepair-swart.vercel.app**

Короче, идея простая. В универе постоянно одна и та же история: есть идея проекта, а команды нет. Или наоборот: ты умеешь писать бэкенд, хочешь сделать что-то реальное, но не знаешь, к кому присоединиться. Команды собираются по знакомству, и в итоге там три питониста и ни одного дизайнера.

CodePair решает именно это. Ты указываешь, что умеешь, а платформа подбирает людей, которые **дополняют** команду, а не повторяют её. Если у вас уже есть бэкенд и ML, она предложит дизайнера или продакта, а не четвёртого Python-разработчика.

## Что уже работает

- вход через GitHub или Google
- профиль: роли, навыки, интересы, уровень, сколько часов в неделю готов уделять
- можно подтянуть языки и репозитории из GitHub
- проекты: создаёшь проект, отмечаешь, кто нужен, и сразу видишь, каких ролей не хватает
- подбор участников с процентом совпадения и объяснением, почему именно этот человек
- AI Team Builder: пишешь идею обычными словами, он сам предлагает роли, стек и заполняет форму
- приглашения и заявки в команду
- завершённые проекты попадают в профиль как подтверждённый опыт (роль, вклад, ссылки)
- Telegram-бот присылает уведомления: приглашения, заявки, новые проекты под твою роль, завершение проекта
- три языка: русский, английский, узбекский
- светлая и тёмная тема и три цвета на выбор: синий, красный и зелёный в стиле Hack The Box

Ролей 53, разбиты по группам: разработка, данные и AI, кибербезопасность (пентест, SOC, форензика, реверс, CTF и т.д.), инфраструктура, тестирование, дизайн и продукт и прочее.

## Как считается подбор

От 0 до 100 баллов:

| За что | Баллы |
|---|---|
| человек закрывает роль, которой не хватает команде | 40 |
| совпадают технологии (учитываются и языки с GitHub) | 25 |
| интересна та же область | 15 |
| уровень опыта | 10 |
| сколько времени готов уделять | 10 |
| уже завершал проекты | до +5 |

Логика лежит в `lib/matching.ts`, веса можно поменять там же.

## Стек

- Next.js 15 + React 19 (TypeScript)
- Supabase: PostgreSQL, авторизация, RLS
- Vercel (хостинг)
- Gemini API для AI Team Builder
- Telegram Bot API

Всё на бесплатных тарифах, так что проект пока не стоил ни копейки.

## Про структуру файлов

Файлы в репозитории лежат «плоско», без папок: `app__projects__page.tsx` — это `app/projects/page.tsx`. Так было проще загружать через веб-интерфейс GitHub. Перед сборкой `restore.mjs` сам раскладывает всё по папкам, на Vercel это происходит автоматически.

## Запустить у себя

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Перед этим создай `.env.local` по образцу `.env.example`: адрес и ключ Supabase, адрес сайта.

Базу настроить так: в Supabase → SQL Editor по очереди выполнить

1. `supabase__schema.sql` — таблицы и права доступа
2. `supabase__telegram.sql` — уведомления для бота
3. `supabase__telegram_webhook.sql` — мгновенная отправка уведомлений
4. `supabase__seed_demo.sql` — по желанию, 8 тестовых студентов, чтобы было на ком проверять подбор

Тесты:

```bash
npm test                              # подбор
python3 -m unittest test_codepair_bot # бот
```

## Telegram-бот

Бот работает прямо на сайте через webhook (`/api/telegram/...`). Для него в Vercel нужны переменные `TELEGRAM_BOT_TOKEN`, `SUPABASE_SECRET_KEY`, `CODEPAIR_BOT_SECRET` и `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`. После деплоя один раз открыть `/api/telegram/setup?secret=...`.

Есть и отдельная версия на Python (`codepair_bot.py`), если захочется держать бота на своём сервере.
